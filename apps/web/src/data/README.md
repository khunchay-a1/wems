# Reference data

`thai-address.json` — province → district (อำเภอ/เขต) → `[subdistrict (ตำบล/แขวง), postcode]`,
expanded from the npm package `thai-address-database@0.0.33` (ISC license,
https://github.com/Sellsuki/thai-address-database). Used by the address fields of the client
and site forms (docs/modules/M02-clients-sites.md §4). Regenerate from the package's
`database/db.json` when a newer release is published.
