# M09 · รายงานและ Dashboard (เฟส 4)

> ตัวชี้วัดคำนวณจากข้อมูลจริงด้วย SQL (view หรือ query ใน `modules/reports`) — ไม่เก็บตัวเลขซ้ำ ยกเว้น snapshot รายวันเพื่อความเร็ว (ตาราง materialized view refresh ทุกคืน)

## 1. ตัวชี้วัด

| กลุ่ม | ตัวชี้วัด | นิยาม |
|---|---|---|
| เอกสาร | เวลาตรวจเฉลี่ย | ค่าเฉลี่ย `completedAt − submittedAt` ของ ReviewCycle ที่ APPROVED แยกประเภทเอกสาร (วันทำการ) |
| เอกสาร | ผ่านรอบแรก | revision ที่ APPROVED ใน `cycleNo = 1` ÷ revision ที่ APPROVED ทั้งหมด |
| เอกสาร | งานตรวจเลยกำหนด | ReviewStep ACTIVE ที่ `dueAt < now()` |
| เอกสาร | ส่งมอบตรงแผน | เอกสารที่ `actualDate ≤ plannedDate` (วัตถุประสงค์ FC) ÷ เอกสารที่มีแผน FC และถึงกำหนดแล้ว |
| เอกสาร | ลูกค้าตีกลับ | รายการใบนำส่งที่ CODE_3/CODE_4 ÷ รายการที่ได้ผลตอบกลับ |
| โครงการ | ความคืบหน้าเทียบแผน | ความคืบหน้าจริง (BR-PRJ-030) ÷ ความคืบหน้าตามแผน ณ วันนี้ (จาก planned dates ของ task) |
| โครงการ | ปัญหาค้าง | Issue ที่ไม่ CLOSED/CANCELLED แยกความรุนแรง |
| แล็บ | TAT ตามกำหนด | ใบรายงานที่ `issuedAt ≤ dueDate` ของงาน ÷ ใบรายงานทั้งหมดในช่วง |
| แล็บ | Backlog | SampleTest แยกสถานะ × พารามิเตอร์ |
| แล็บ | QC ไม่ผ่าน | batch QC_FAILED ÷ batch ทั้งหมด |
| แล็บ | เกิน holding time | จำนวนรายการ `holdingTimeExceeded` |
| ขาย | Pipeline | มูลค่าใบเสนอราคาตามสถานะ (ฉบับล่าสุดของแต่ละเลข) |
| ขาย | อัตราชนะ | ACCEPTED ÷ (ACCEPTED + REJECTED + EXPIRED) |
| การเงิน | ค้างวางบิล / ค้างรับ | BillingRecord REQUESTED / INVOICED ที่ยังไม่ PAID |
| ลูกค้า | แนวโน้มคุณภาพน้ำ | ผลพารามิเตอร์ต่อจุดเก็บตามเวลา พร้อมเส้นเกณฑ์มาตรฐาน |

## 2. หน้าจอ

- `/dashboard` (ทุกคน): งานของฉัน — ขั้นตรวจที่รอ, ความเห็นที่ต้องตอบ, ปัญหาที่รับผิดชอบ (เฟส 2), รายการแล็บที่รอ (เฟส 3)
- `/dashboard/executive` (`dashboard.executive`): KPI tiles + กราฟแนวโน้ม 12 เดือน + ตารางโครงการเสี่ยง
- `/reports`: รายงานส่งออก Excel — ทะเบียนเอกสาร/MDL, สรุปงานตรวจ, ปัญหาหน้างาน, ผลแล็บตามลูกค้า/ช่วงเวลา, ต้นทุนแรงงาน
- กราฟใช้ Recharts; ใช้สีและรูปแบบตาม design token ของเว็บ; ทุกกราฟมีตารางข้อมูลให้ดู/ส่งออกได้

## 3. รายงานส่งอีเมลตามเวลา

- ผู้บริหาร: สรุปรายสัปดาห์ ทุกวันจันทร์ 08:00 (KPI หลัก + โครงการเสี่ยง + งานตรวจเลยกำหนด)
- PM: สรุปรายสัปดาห์ของโครงการตัวเอง (เอกสารค้าง ใบนำส่ง ปัญหา)

## 4. API

`GET /reports/kpis?group=documents|projects|lab|sales&from=&to=`, `GET /reports/{reportCode}?format=xlsx&...`, `GET /dashboard/me` — สิทธิ์ตามตัวชี้วัด (`dashboard.executive`, `report.export`, หรือขอบเขตโครงการ)
